# Точка · Платёжный симулятор

Небольшое демо для тестирования сценария оплаты: успешная операция или отказ, история текущей сессии и скачивание чека в PDF.

## Запуск

```sh
npm install
npm run dev
```

Откройте URL, который выведет Vite (обычно `http://localhost:5173`). Для production-сборки используйте `npm run build`.

Все операции выполняются локально в браузере. Платёжные реквизиты не запрашиваются, реальные деньги не списываются. Создаваемый чек является демонстрационным и не заменяет фискальный документ; история хранится только до перезагрузки страницы.
